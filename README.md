# 데일리 미니게임 🎮

매일 한국(+글로벌) 바이럴 소재 3개를 골라, 30~60초짜리 모바일 미니게임 3개로 만드는 저장소입니다.

- 🕹️ 플레이: https://jeonghwanko.github.io/daily-minigames/
- 📁 구조: `games/YYYY-MM-DD/<slug>/index.html` (빌드 없는 단일 HTML 파일)
- 📝 날짜별 `games/YYYY-MM-DD/README.md`에 소재, 화제가 된 이유(출처 링크), 게임 아이디어를 기록합니다.

## 원칙

- 모바일 세로 화면 우선, 터치·마우스 모두 지원, 탭하면 바로 시작
- 결과 화면에서 점수 공유(공유 시트 또는 클립보드 복사)
- 광고·추적 없음, 소리는 기본 꺼짐
- 캐릭터·그래픽은 모두 원작이며, 실존 인물·저작권 캐릭터·상표를 쓰지 않습니다. 언급된 트렌드·브랜드와 제휴 관계가 없습니다.
